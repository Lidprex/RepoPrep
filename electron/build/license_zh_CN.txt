隐私政策 — Lidprex Labs 出品的 RepoPrep

您的数据属于您。RepoPrep 完全在您的机器上运行：零遥测、零跟踪、零数据收集。

我们的隐私方针
RepoPrep 是一款完全运行在您本地电脑上的桌面应用。它从不联网回传、从不将您的文件发送到远程服务器，也从不收集使用统计。我们为像您一样重视隐私与效率并重的开发者打造了这款工具。
清理引擎在本地处理您的仓库。每一项操作——扁平化、清理、扫描——都发生在您的文件系统边界之内。正常操作过程中的任何一个环节都不会通过网络传输数据。

我们收集什么
完全没有。RepoPrep 不收集、不存储、不传输任何个人数据、使用指标、崩溃报告或分析数据。
无需账户。没有登录、没有注册、没有用户档案。下载即可运行。
完全离线。应用不需要联网。没有后台服务、没有更新提示、没有遥测。

您的文件
RepoPrep 仅读取您的项目文件以分析其结构并识别构建产物。它从不读取源代码的语义内容。文件树只按模式扫描——node_modules、venv、dist、构建产物、缓存目录——仅此而已。
使用 AI 扁平化模式时，工具会将源文件复制到一个扁平的输出目录。输入和输出目录都在您的本地机器上。我们没有任何访问、复制或传输这些文件的机制。

第三方服务
RepoPrep 在运行时零外部依赖。独立的可执行文件包含它所需的一切。它不嵌入分析 SDK、崩溃报告器或广告库。您的机器发出的唯一网络请求是您自己选择的——例如从 GitHub Releases 下载应用或访问本文档。

更新
RepoPrep 不包含自动更新程序。发布新版本时，您可以从 GitHub Releases 页面手动下载。升级不会影响您现有的配置和已清理的项目。

联系方式
如果您对本隐私政策或任一 Lidprex Labs 产品的数据处理实践有疑问，请通过我们的主站联系我们，或在 GitHub 上提交问题。
